# Data in this snapshot

## Included

- `uk/`: input distributions (age, income–age and income–wealth joint
  distributions, buy-to-let probability by income percentile, initial sale and
  rent mark-ups), as distributed with
  [INET-Complexity/housing-model](https://github.com/INET-Complexity/housing-model).
- `spain/`: the corresponding Spanish inputs, as distributed with
  [adrian-carro/housing-model-spain](https://github.com/adrian-carro/housing-model-spain),
  derived from the Banco de España *Encuesta Financiera de las Familias* (EFF).
- `euroarea/`: a Python script for summary moments of simulated runs (no data).

## Not included

- Research calibration data and empirical inputs beyond the upstream inputs.
- Simulation output and research results.
